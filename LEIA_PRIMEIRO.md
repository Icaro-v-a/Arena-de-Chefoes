# Arena de Chefões — projeto inicial (alunos)

1. Leia `README.md`.
2. Execute `INICIAR_WINDOWS.bat` ou `bash INICIAR_LINUX_MAC.sh`.
3. Abra http://localhost:8080.
4. Implemente os `TODOs` de `src/Batalha.java` e `web/app.js`.
5. Teste golpes comuns, golpes especiais, defesa, cura e vitória/derrota.
6. Personalize a interface e implemente pelo menos um desafio extra.

**Já está pronto:** servidor HTTP em Java, rotas GET/POST, HTML e CSS iniciais, botões, reinício de partida, formato do JSON e geração do aviso para o próximo contra-ataque.

**Você implementa:** regras do combate no Java, requisição POST de ação no JavaScript, atualização das barras de vida, atualização do aviso e indicação de vitória/derrota.

⚠️ Não abra duas instâncias na porta 8080. O estado da partida fica na memória do Java; reiniciar o processo apaga a partida.
